# Volunteer Coordination System

A web-based application for managing volunteers during warming room operations.

## Features

- **Volunteer Management**: Registration, training tracking, skill recording
- **Shift Scheduling**: Automated scheduling with backup coverage
- **Communication**: Multi-channel notifications (SMS, email, phone)
- **Reporting**: Volunteer hours, coverage metrics, incident tracking
- **Mobile-Friendly**: Responsive design for smartphones and tablets

## Installation

1. Copy files to your web server
2. Import `database/schema.sql` into your MySQL database
3. Configure database settings in `config/database.php`
4. Run `install.php` to complete setup

## Requirements

- PHP 7.4+
- MySQL 5.7+
- Web server (Apache/Nginx)
- SSL certificate (recommended)

## Quick Start

1. Access the application at `https://yourdomain.com/coordination-system/`
2. Complete initial coordinator setup
3. Add volunteers and create shift templates
4. Begin scheduling for warming room activations

For detailed documentation, see the `docs/` folder.
