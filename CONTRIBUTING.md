# Contributing to NWRP

Thank you for your interest in contributing to the Northumberland Warming Room Proposal! This guide will help you participate effectively in this important community initiative.

## How to Contribute

### 1. Share Ideas & Brainstorm

The easiest way to contribute is by sharing your ideas:

- **Review** the [BRAINSTORMING.md](BRAINSTORMING.md) document
- **Add** your ideas directly to the relevant sections
- **Create** detailed proposals in the `proposals/` directory for complex ideas
- **Comment** on existing ideas through GitHub issues

### 2. Improve Documentation

Help make our documentation better:

- Fix typos and clarify unclear instructions
- Add examples and use cases
- Translate documents to other languages
- Update outdated information

### 3. Develop Tools & Utilities

Contribute to the technical tools:

- Improve the warming room status tool
- Add new features to existing tools
- Create new utilities that help operations
- Write tests and documentation

### 4. Review & Provide Feedback

Your perspective matters:

- Review proposals and provide constructive feedback
- Share your expertise in relevant areas
- Help identify potential challenges
- Suggest improvements to existing ideas

## Contribution Guidelines

### Be Respectful

- Use welcoming and inclusive language
- Respect differing viewpoints and experiences
- Focus on what's best for the community
- Show empathy towards other participants

### Be Constructive

- Provide specific, actionable feedback
- Explain the reasoning behind your suggestions
- Acknowledge good ideas from others
- Focus on solutions, not just problems

### Be Collaborative

- Work together towards common goals
- Share credit and acknowledge contributions
- Help newcomers get started
- Build on each other's ideas

## Making Changes

### For Simple Changes

1. **Fork** this repository (or clone if you have access)
2. **Create** a new branch for your changes
3. **Make** your changes
4. **Commit** with clear, descriptive messages
5. **Submit** a pull request

### For Proposals

1. **Create** a new file in `proposals/` directory
2. **Use** the proposal template from BRAINSTORMING.md
3. **Fill in** all relevant sections
4. **Submit** a pull request with your proposal
5. **Engage** in discussion when others provide feedback

### Commit Message Guidelines

Write clear commit messages:

- Use present tense ("Add feature" not "Added feature")
- Use imperative mood ("Move cursor to..." not "Moves cursor to...")
- Limit the first line to 72 characters or less
- Reference issues and pull requests when relevant

Examples:
```
Add volunteer scheduling section to brainstorming
Fix typo in contributing guidelines
Update warming room status tool with SMS notifications
```

## Code Contributions

### For Python Scripts

- Follow PEP 8 style guidelines
- Add docstrings to functions and classes
- Include type hints where appropriate
- Write tests for new functionality
- Update documentation

### For Documentation

- Use clear, simple language
- Include examples where helpful
- Organize content logically
- Check spelling and grammar
- Use markdown formatting consistently

## Getting Help

If you need help:

- **Read** the documentation in this repository
- **Ask** questions by opening a GitHub issue
- **Look** at existing issues and discussions
- **Reach out** to maintainers if needed

## Recognition

All contributors will be recognized for their efforts. Significant contributors may be listed in a CONTRIBUTORS.md file.

## Code of Conduct

### Our Pledge

We are committed to providing a welcoming and inspiring community for everyone. We pledge to make participation in this project a harassment-free experience for everyone, regardless of:

- Age, body size, disability, ethnicity
- Gender identity and expression
- Level of experience, education
- Nationality, personal appearance
- Race, religion, or sexual identity and orientation

### Our Standards

**Positive behaviors include:**
- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Gracefully accepting constructive criticism
- Focusing on what is best for the community
- Showing empathy towards others

**Unacceptable behaviors include:**
- Harassment, intimidation, or discrimination
- Trolling, insulting/derogatory comments
- Public or private harassment
- Publishing others' private information
- Other conduct which could reasonably be considered inappropriate

### Enforcement

Instances of unacceptable behavior may be reported to the project maintainers. All complaints will be reviewed and investigated promptly and fairly.

## Questions?

If you have questions about contributing, please open an issue with the "question" label, and we'll be happy to help!
