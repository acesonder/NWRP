# NWRP - Northumberland Warming Room Proposal

Welcome to the Northumberland Warming Room Proposal repository! This project serves as a collaborative space for planning, organizing, and managing the warming room initiative.

## About

The warming room is a critical community service providing shelter and warmth during cold weather for those in need. This repository contains:

- **Brainstorming & Ideas**: Collaborative space for proposals and improvements
- **Utility Tools**: Scripts and tools to help manage warming room operations
- **Documentation**: Guidelines for contributing and participating

## Warming Room Status Tool

A simple utility to check and manage warming room activation status.

### Usage

```bash
python warming_room_status.py --check
```

See [docs/TOOL_USAGE.md](docs/TOOL_USAGE.md) for detailed usage instructions.

## Getting Started

1. Read through the [BRAINSTORMING.md](BRAINSTORMING.md) to see current ideas
2. Check [CONTRIBUTING.md](CONTRIBUTING.md) for how to participate
3. Use the warming room status tool to stay informed about activations
