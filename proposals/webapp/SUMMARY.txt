🔌 API ENDPOINTS
─────────────────────────────────────────────────────────────────────────────
Proposals API (api/proposals.php):
  GET  ?action=list                    - List proposals
  GET  ?action=get&id=1                - Get single proposal
  POST action=create                   - Create proposal
  POST action=update&id=1              - Update proposal
  POST action=delete&id=1              - Delete proposal
  GET  ?action=comments&proposal_id=1  - Get comments
  POST action=add_comment              - Add comment

Configuration API (api/config.php):
  GET  ?action=get                     - Get all config
  POST action=update                   - Update config

Testing API (api/test_connection.php):
  GET                                  - Test database connection

🚀 QUICK START GUIDE
─────────────────────────────────────────────────────────────────────────────
1. Install Prerequisites:
   sudo apt-get install apache2 php php-mysql mysql-server

2. Create Database:
   mysql -u root -p < database_schema.sql

3. Configure Application:
   cd config/
   cp database.example.php database.php
   nano database.php  # Edit credentials

4. Set Permissions:
   chmod 644 config/database.php

5. Access Application:
   http://your-domain/proposals/webapp/install.php

6. Follow On-Screen Instructions
   Test connection → Configure settings → Start using!
